# Voices-Speech-Recognition-445
Speech recognition system tested on TenVoices, a dataset we recorded from 10 speakers (~1,200 English utterances, Bangladeshi accent). Compares MFCC + k-NN/SVM/RF/XGBoost/DTW, zero-shot Vosk, wav2vec2 and Whisper, and our Whisper + LoRA with noise augmentation and a Bangladeshi lexicon, using speaker-independent 5-fold CV. NSU course project.
