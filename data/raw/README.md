# data/raw/

Local copies of the two source datasets, downloaded in **T41** (M2) as described in [docs/DATASETS.md](../../docs/DATASETS.md):

- `fsc/`: Fluent Speech Commands,
- `l2arctic/`: L2-ARCTIC v5.0.

The datasets' licences do not allow re-publishing the audio, so everything here except this README is gitignored. The original archives are in the team's private Drive.
