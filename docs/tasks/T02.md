## Build

1. **Session plan** `make_session_plan(speaker_id, phrases, seed=None) -> list[dict]`: rounds 1–3 with all 50 phrases each, shuffled differently per round (seed from the speaker ID and round, so a restarted session gets the same order), then the noisy block with the 10 `noisy_take` phrases. Each item: `speaker_id, phrase_id, text, category, rep, condition`.
2. **File naming** `clip_path(raw_dir, speaker_id, phrase_id, rep, condition)` → `data/raw/<SPK>/<SPK>_<PHRASE>_r<REP>_<COND>.wav` (protocol §8).
3. **Saving a take** `save_take(item, sample_rate, samples)`: write a 16-bit WAV at the microphone's own rate (no resampling; 48 kHz expected) and add or replace that clip's row in `data/metadata/utterances/<SPK>.csv` (columns from `utterances_template.csv`; `duration_s`, `orig_sample_rate`, `peak_dbfs` filled in, `qc_status` empty). A re-record overwrites the file and the row.
4. **Speaker form**: writes `data/metadata/speakers/<SPK>.csv` (columns from `speakers_template.csv`; no names or phone numbers).
5. **Gradio UI** `python -m tools.recorder --speaker S03`: shows the phrase text large, the round and progress (e.g. 37 / 160), Record / Re-record / Next / Back, a level warning when the peak is above −0.5 dBFS, and resumes where the session stopped (clips that already exist are skipped).
6. **Phrase sheets** `python -m tools.recorder --sheet S03`: a printable Markdown or HTML file in `outputs/` with the 3 rounds and the noisy block in session order.

One metadata file **per speaker** is required: members record on their own branches, and per-speaker files never conflict when merged.

## Tests (`tests/test_recorder.py`)

- The plan has 160 items: 150 clean (each phrase once per round, rounds in different orders) + 10 noisy; the same speaker and seed give the same plan.
- `clip_path` gives the protocol name, e.g. `S07/S07_CMD02_r1_clean.wav`.
- `save_take` with a synthetic tone in a temporary folder writes the WAV and exactly one metadata row; saving again replaces the row.

## Done when

- `python -m unittest discover -s tests -v` passes.
- A short test session (a few takes) saves correctly named WAVs and correct metadata rows. Delete the test audio afterwards; never commit audio.
