## Write these sections

1. **Purpose and freeze rule.** The plan is frozen when M1 merges it. Later changes need M1's approval and a dated entry in a *Deviations* section at the end.
2. **Data.** 10 speakers × 50 phrases × 3 clean repetitions (1,500 clean clips) + 10 noisy takes per speaker (100). Noisy takes are never used for training.
3. **Splits.**
   - Random split: stratified 80/20 by phrase, seed 42; 10% of the training part for validation.
   - Speaker-independent CV: 5 folds, 2 test speakers (one female, one male where possible), 1 validation speaker, 7 training speakers; every speaker tested exactly once.
   - Whisper is zero-shot: scored on the same test clips, uses no training data.
4. **Runs.** A table of every run with its folder in `results/`: `random_forest`, `xgboost`, `knn`, `svm`, `w2v2_untrained`, `w2v2_3ep`, `w2v2_8ep_noise`, `w2v2_15ep_noise`, `w2v2_15ep`, `whisper_small`.
5. **Metrics.** Accuracy (primary), macro F1, weighted F1, per-class F1, confusion matrix, per-speaker accuracy; WER and CER for Whisper. For the 5 folds, say how results are combined: pool the predictions of all folds (each clip is tested once, so 1,500 test predictions) for the headline numbers, and also report mean ± standard deviation over folds.
6. **Hypotheses H1–H5.** For each one: the exact comparison (which runs, which split), the test (from `support/stats.py`, task T33), and the pass criterion from the project plan. Write them so that anyone can decide *pass* or *fail* from the numbers without judgement.
7. **Statistical tests.** Bootstrap 95% CI (10,000 resamples, seed 42), exact McNemar, Wilcoxon signed-rank over the 10 speakers, α = 0.05. State whether you correct for multiple comparisons (e.g. Holm across H1–H5) and why.
8. **Model selection and leakage rules.** Hyper-parameters and best epochs chosen on validation data only; no speaker in more than one of train / validation / test within a fold; noisy takes never in training.
9. **Reporting.** Every hypothesis is reported whether it holds or not; the figures and tables that will show each one.
10. **Deviations.** Empty table (date, change, reason, approved by).

## Done when

- Nothing contradicts `docs/PROJECT_PLAN.md`. If you think the plan should change, write it under **Requests for the lead** instead of changing it here.
- M1 approves it when merging; from then on it is frozen.
