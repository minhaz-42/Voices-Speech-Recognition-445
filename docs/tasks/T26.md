# T26 · Subset release (M2 · Rabbi)

| | |
|---|---|
| **Goal** | Let anyone rebuild TenVoices exactly: publish the lists and scripts (never the audio, which the licences forbid) |
| **Depends on** | T09 (your own) |
| **You create** | `tools/make_release.py`, `tests/test_make_release.py` |

## Build

`python -m tools.make_release` writes `outputs/release/tenvoices-subsets-v1.zip` with `data/subsets/*.csv`, `data/prompts/fsc_phrases.csv` (and the L2 files once they exist), `data/splits/`, `tools/select_subsets.py`, `tools/qc_report.py`, `data/README.md`, `data/SOURCES.md` and a `SHA256SUMS` file. The test builds it from a temporary folder and checks the contents and checksums. Then create a **draft** release with `gh release create subsets-v1 outputs/release/tenvoices-subsets-v1.zip --draft --title "TenVoices subsets v1"`; Tanvir publishes it at the end.

## Done when

- Tests pass; the draft release exists.
