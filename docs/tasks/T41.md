## Do

1. **L2-ARCTIC first, because the link comes by email:** fill in the form on the [official page](https://psi.engr.tamu.edu/l2-arctic-corpus/) (licence box ticked), download v5.0 and extract it so the speaker folders sit in `data/raw/l2arctic/` (e.g. `data/raw/l2arctic/ASI/wav/arctic_a0001.wav`).
2. **Fluent Speech Commands:** follow *Access the dataset here* on the [official page](https://fluent.ai/research/fluent-speech-commands/). If that link no longer works, use one of the public copies listed in `docs/DATASETS.md` §1. Extract it into `data/raw/fsc/`.
3. **Check the counts** from the repository root:
   ```bash
   python - <<'EOF'
   import glob, pandas as pd
   for f in sorted(glob.glob("data/raw/fsc/**/data/*_data.csv", recursive=True)):
       df = pd.read_csv(f)
       print(f, "clips:", len(df), "speakers:", df["speakerId"].nunique())
   EOF
   ls data/raw/l2arctic                       # 24 speaker folders
   ls data/raw/l2arctic/ASI/wav | wc -l       # about 1,130 clips
   ```
   Fluent Speech Commands must show **23,132 / 3,118 / 3,793** clips and **77 / 10 / 10** speakers (train / valid / test), as in the paper's Table 1. If the speaker column has another name, use that name and note it.
4. **Checksums:** `shasum -a 256 <archive>` (macOS), `sha256sum <archive>` (Linux) or `certutil -hashfile <archive> SHA256` (Windows).
5. **Team Drive:** upload the two original archives to `TenVoices/raw/fsc/` and `TenVoices/raw/l2arctic/`. Never share them publicly.
6. **Write `data/SOURCES.md`:** one section per dataset with the URL you actually used (official page or which public copy), version, download date, licence, archive file name and SHA-256, and the counts from step 3. Also list the columns of the FSC demographics file (T42 needs the gender column).
