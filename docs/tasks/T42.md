## Build

The selection rules are in `docs/DATASETS.md` §2. Implement them exactly; if a rule cannot work on the real data, write it under **Requests for the lead** instead of changing it.

1. **Readers** (the only functions that know the datasets' file layout):
   - `read_fsc(raw_dir) -> pandas.DataFrame`: the three split CSVs plus the demographics file → one row per clip with `speaker_id, gender, l1, text` (normalised as in §2), `category` (the action), `source_path`.
   - `read_l2arctic(raw_dir, speakers) -> pandas.DataFrame`: one row per clip of the 10 configured speakers with `speaker_id, gender, l1, phrase_id` (the prompt ID), `text`, `source_path`. Gender and first language come from the table in `docs/DATASETS.md`.
2. **Durations:** `add_durations(df, raw_dir)` adds `duration_s` (after trimming, no padding) and `sha256`. Cache them in `outputs/durations_<dataset>.csv` so a rerun takes seconds.
3. **Selection** (pure functions on DataFrames, so they can be tested without audio):
   - `select_fsc(df, n_phrases=50, per_gender=5, takes=2, seed=42) -> (clips, phrases)`
   - `select_l2arctic(df, speakers, n_phrases=50, seed=42) -> (clips, phrases)`
   - Both drop clips that are not eligible (0.5–6 s) and accept `exclude`: a set of source paths that QC (T43) rejected.
4. **Writing:** `write_outputs(clips, phrases, dataset)` writes the two files per dataset with the columns in `docs/DATASETS.md`, sorted by `utt_id` / `phrase_id`, so a rerun produces byte-identical files.
5. **CLI:** `python -m tools.select_subsets --dataset fsc|l2arctic|all [--exclude data/subsets/qc_fsc.csv]`, printing the number of speakers, phrases and clips selected.
6. **`support/phrases.py`:** add a `dataset` argument: `load_phrases(dataset="fsc")` reads the list from the `datasets` section of the config (columns `phrase_id, category, text`; `noisy_take` defaults to `False` when the column is absent) and checks 50 unique IDs and 50 unique texts. Without `dataset`, it keeps reading the old `data/prompts/phrases.csv` exactly as now: `tests/test_whisper_asr.py` still uses it until T30.

## Tests (`tests/test_select_subsets.py`, synthetic data only)

- FSC: 12 synthetic speakers (6 F, 6 M) and 60 phrasings with uneven coverage → the 50 phrasings with the most two-take speakers are chosen (ties alphabetical) and the best-covered 5 F and 5 M speakers are chosen.
- FSC: a clip of 7 s or of 0.3 s is never selected; a path in `exclude` is never selected.
- L2-ARCTIC: a prompt missing for one speaker, or with different text for one speaker, is not eligible; exactly 50 of the eligible prompts are drawn.
- The same seed gives identical output; the written CSVs have exactly the columns in `docs/DATASETS.md`.
- `load_phrases(dataset=...)` on a small temporary list works, and rejects duplicate IDs.
