HOW WE MEASURE

  • Leave-2-speakers-out 5-fold cross-validation
  • Headline: unseen speakers + unseen sentences
  • WER · CER · command accuracy · real-time factor
  • Noise sweep 20 → 0 dB + real noisy takes
  • 95% bootstrap CIs + Wilcoxon signed-rank tests

HYPOTHESES · FIXED BEFORE TESTING

  • H2+20 points on Bangladeshi names
  • H3DTW fails across speakers; ASR commands ≥ 95%
  • H4Degrades less at 5 dB and 0 dB SNR
